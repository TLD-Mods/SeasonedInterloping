# Seasoned Interloping

⚠️ This is a TLD Community Mod, which may or may not be maintained in the future. ⚠️ 

This adds the following regions to Interloper mode:

- Bleak Inlet
- Forsaken Airfield
- Zone of Contamination
- Sundered Pass
